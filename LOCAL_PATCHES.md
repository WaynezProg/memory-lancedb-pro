# Local patches for this OpenClaw deployment

Upstream integration base: CortexReach/memory-lancedb-pro `c0e2c7a3a8b5780b6133ddfd9e2f426bf0ea1b6c`.
This file records the deployment-specific behavior that must be reviewed on future upstream updates. The pre-integration baseline is commit `709baaa19e52193fa17e656880a7373274fb7f29` plus the live uncommitted diff and four untracked source/runtime/test files captured in `diagnostics/plugin-update-20261028/lancedb-live.patch` and the isolated snapshot commit.

- **FIFO write lock queue** (`src/store.ts`, compiled `dist/src/store.js`): serialize same-instance acquisitions before the shared file/Redis write lock; route `patchMetadata` through the same path. Without this ordering, two concurrently started updates can acquire the external lock in reverse order, and a failure/rollback can violate callers' expected ordering. `test/local-write-lock-queue.test.mjs` tests actual LanceDB concurrent store/update/delete, rollback and both optimize paths; `test/update-consistency-lancedb.test.mjs` exercises the observed stalled update scenario. Both `foldIndices` and `runStorageMaintenance` use `runWithWriteLock`.
- **Memory governance and lifecycle** (`src/smart-metadata.ts`, `src/tools.ts`, `src/retriever.ts`, `src/store.ts`): preserve active/history/review selection, metadata transitions, relationship arrays, scope and suppression filters, and current local conflict-review and recall protections. Combined with upstream retrieval cancellation, batching, scope enforcement and atomic supersede. Tests include `governance-lifecycle-contract`, `memory-governance-tools`, `recall-text-cleanup`, `store-excludeinactive-default`, and `manual-store-supersede`.
- **Workspace provenance** (`src/workspace-memory-provenance.ts`, `src/openclaw-memory-capability.ts`): realpath containment and host provenance/taint check before trusting curated memory files; upstream's static path classifier does not provide equivalent protection. Test `workspace-memory-provenance.test.mjs`.
- **Exact legacy hex IDs** (`src/store.ts`): check exact non-UUID hex IDs first and scan all IDs for prefix ambiguity, including rows beyond the old 1000-row cap, for update/delete. Retain upstream raw-scope and rollback protections. Test `hex-id-exact-match.test.mjs`.
- **Isolated instance paths** (`index.ts`): default state and mdMirror to this pinned instance when OPENCLAW_STATE_DIR is absent, honor OPENCLAW_WORKSPACE_DIR, and read workspace-map fallback from the same state or an explicit OPENCLAW_CONFIG_PATH. Tests `mdmirror-fallback-dir` and `mdmirror-workspace-map-entries`.
- **Ingress and recall boundary** (`src/auto-capture-cleanup.ts`, `src/auto-recall-query.ts`, `src/recall-envelope.ts`): strip only trusted OpenClaw metadata carriers and extract the current request instead of treating injected history as an instruction. Tests `auto-recall-query`, `noise-filter-artifacts`, and `recall-envelope`.

LCM retains its separately tracked internal-session-effects isolation patch in `diagnostics/plugin-update-20261028/lcm-source/src/tools/lcm-conversation-scope.ts`; the official 1.2.0 package does not include it. Tests are in `lcm-delegated-conversation-scope.test.ts`.
